# The lock of connected levels finds its station by matching parameters

The game gives a check function only the values of the panel, never the entity that is edited. The script therefore finds the station whose stored parameters equal those values, asks the engine which free nodes of it have foreign edges, and locks the level of each such node. Stations with equal values count together. When the player changes a value, the values match no station, so the script keeps the stations of the last match until another match replaces them. A hidden parameter that cannot change after construction tells the script whether a station is being placed or edited, because the game leaves such a parameter out of the values of a built station. The alternative, an event hook that records the selected station in a second script, depends on state shared between two scripts, which is not confirmed. If the game ever passes the entity, this code is replaced by a direct lookup.
